# Swastik's Showcase
This is my personal website to demostrate my projects and skills. Currently it only contains basic welcome text and shaders for background because this was my first time learning shaders and there were so facinating i gave all my time to studying and improving them.
### Note: ### 
This website is not made for please use it only on a laptop screen (1920 * 1080 resolution).
# How to Run
go to https://swastikgupta-code.github.io/My_Portfolio/ and the website will run for controls see the section below
# Controls
You just need to click at any world to enter it, you can scroll the worlds by using mouse wheel, touch and mouse movement and after entering a world you will see a black button on the top right corner that is for going back to the world selector page , you will also see buttons on buttom right and bottom left corners these button take you to the next and previous world. 
### Note:
you will not see previous and next button on first and last page respectively.
